# Vinayak Mishra — Data Analyst Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Structure

- `index.html` — portfolio content
- `style.css` — responsive styling
- `script.js` — mobile navigation + reveal animations
- `assets/` — put your resume PDF and project screenshots here

## Before publishing

Replace these placeholders in `index.html`:

1. `YOUR_EMAIL@example.com`
2. GitHub URL
3. LinkedIn URL
4. X URL
5. Project `href="#"` links
6. `assets/Vinayak_Mishra_Resume.pdf` with your actual resume file

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy with GitHub Pages

1. Create a GitHub repository, e.g. `vinayak-portfolio`.
2. Upload all files.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save.

Your portfolio will then be available at your GitHub Pages URL.
